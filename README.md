🚀 Steps to Start an Angular App

Install Node.js & npm

Download and install Node.js (it comes with npm).
Verify installation:
Bash

Copy code
node -v
npm -v
Install Angular CLI

Angular CLI is the tool that sets up and manages Angular projects.
Bash

Copy code
npm install -g @angular/cli
Create a New Angular Project

Run:
Bash

Copy code
ng new my-angular-app
Choose options (routing, stylesheet format) as prompted.
Navigate to Your Project Folder

Bash

Copy code
cd my-angular-app
Start the Development Server

Bash

Copy code
ng serve
Open your browser and go to http://localhost:4200 — your app is live!
💡 Quick Tips

Use ng generate component component-name to add new components.
Keep your code organized in src/app.
The CLI handles most boilerplate, so focus on building features.
